# Dyfire 0.4.7

统一账户入口的视觉，并修复手机端下拉选项重复打开的问题。

- 登录、注册、找回密码和修改密码页面沿用新版首页的暖色卡片、留白、圆角和主题颜色；统一字段、按钮、密码显示开关和错误反馈。
- 登录与注册切换保留滑块和表单过渡，支持减弱动画偏好。手机端保留安全边距和触控尺寸，输入字号避免 iOS 聚焦时自动放大。
- 全站共用选择器拦截 Safari 触摸之后的原生选择动作，同一次操作只显示站内列表。保留键盘操作、辅助技术点击、禁用和多选控件的原有行为。
- 修复续火任务“更多”菜单被后续行按钮遮盖的问题；菜单使用独立弹层并跟随触发控件定位，检查桌面和手机端的显示与操作。
- 修复找回密码输入错误代码后跳到不存在页面的问题，现在回到原表单显示错误并允许重试。
- 增加 Chromium 和 WebKit 触屏回归，以及隔离后端的注册、登录、修改密码、找回错误处理验收。WebKit 测试是移动浏览器模拟，不等同于 iPhone 真机验收。

本版可使用“仅更新网页”部署。沿用 0.4.6 的固定运行环境和镜像层，登录与发送服务无需重启。服务器仍使用 GHCR，不增加国内镜像仓库或额外凭据。
