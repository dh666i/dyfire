# Dyfire 0.4.13

## 新增

- 账号绑定与复核窗口常驻显示输入框，可提交手机号、验证码或页面要求的内容，并可切换密码输入模式。
- 管理后台将相关入口整理为“服务公告”，支持查找接收用户、发布和撤回公告；旧入口继续兼容。
- 执行记录审计列表支持分页，搜索条件变化时回到第一页。

## 修复

- 云端画面轮询失败时保留最近一帧，不再在正常刷新间隙闪出临时错误和重试提示；真实失败仍保留反馈与重试入口。
- 好友后台同步的同步排队函数为同步调用时，不再因错误地 `await` 布尔返回值而中断后台轮询。
- 自动好友同步在应用数据库队列限额前过滤尚未生效的订阅，避免占满候选窗口后漏掉符合条件的账号。
- 管理后台用户数据更新后按当前筛选重新读取，避免旧请求结果覆盖较新的页面状态。
- 修正登录验证相关浏览器回归检查，并补充订阅兑换后额度刷新的隔离验收。

## 维护

- 删除已停用的旧前端入口文件；主构建只使用 React 前端。
- 将头像、贴纸、任务确认和聊天核心测试加入 GitHub Actions 的完整隔离测试集合。
- 管理后台不再展示收款记录和服务成本估算面板；历史数据、服务接口与用户删除保护保持不变。

## 兼容性与升级

- 数据库兼容协议不变，无需手动迁移。
- 本版包含账号验证后台与好友同步服务修复，请执行完整服务更新，使 Web、auth、worker、monitor 四个服务运行同一版本。
- 发行镜像由 GitHub Actions 完成测试、容器验收和安全扫描后原样提升；服务器只拉取固定摘要镜像。
