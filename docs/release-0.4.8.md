# Dyfire 0.4.8

增加好友续火花状态查看与筛选，展示真实读取到的连续天数、点亮/熄灭/重燃状态、已观察到的变化记录和里程碑。

- 在首页任务卡片和好友选择器展示续火花摘要；好友列表可按火花状态筛选，并按天数或昵称排序。
- 新增账号范围内的火花历史接口与详情视图，支持查看已观察到的状态变化和 100、365、520、1000 天里程碑。
- 从已同步会话中读取抖音页面可见状态及会话数据；只有与账号内稳定好友身份匹配的数据才会写入。未知值保持未知，不从昵称、消息文本、缺席记录或日期推算天数和状态。
- 火花观察、历史和里程碑使用新增数据库表；SQLite 使用迁移 26/27，PostgreSQL 随新建表结构提供相同模型约束。历史观察记录按 365 天清理，每个好友最多保留 1000 条变化记录。
- 无法从抖音页面读取到的数据会标记为待同步；火花信息是平台可读取数据的展示，不影响原有任务发送和账号登录流程。

本版同时更新 Web API、数据库模型和浏览器会话读取代码，必须执行完整服务更新；不能只更新 Web。更新器会在活跃扫码或发送任务期间拒绝切换。发布仍须通过同一提交的完整测试、容器验收和高危/严重漏洞扫描。
