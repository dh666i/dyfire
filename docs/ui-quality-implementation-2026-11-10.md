## 选型与维护

新增并固定 `@base-ui/react` 1.9.0、`sonner` 2.0.8、`@number-flow/react` 0.6.2。保留现有 Motion 12；未为引入 Animate UI 升级动画主版本，也未引入第二套动画运行时。

应用 Impeccable 的视觉审查方法和 Emil 的动效、手机交互规范，结合本站既定设计调整。没有安装或启动 Impeccable Live 代理流程。玻璃采用现有 CSS 能力细化，没有添加 WebGL 折射运行时；这不是 React Bits Glass Surface 的完整移植。

共用按钮、弹窗、手机面板、通知分别拆到 `ui-controls.jsx`、`ui-dialog.jsx`、`ui-panels.jsx`、`ui-feedback.jsx`，样式集中在 `ui-quality.css`。保留原业务接口与页面调用方式。抖音远程画面和验证码区域没有加入底部面板关闭手势。

依赖单独打包为可缓存的 `vendor-ui`，本次约 215.50 kB，gzip 72.27 kB。应用入口约 437.64 kB，gzip 137.68 kB；CSS 约 411.73 kB，gzip 121.60 kB，含现有中文分段字体声明。此处为构建产物大小，不是手机首屏速度或运行帧率结论。

依赖许可保存在 `frontend/public/licenses/ui-components.txt`，生产构建会保留。组件状态页不是生产构建入口。
