# 运行与验收工具

本项目只有管理员和普通用户。兑换码和邀请码由管理员直接完整查看、复制；不增加员工权限、验证器或额外查看步骤。不启用周期备份。

## 只读站外健康检查

`python scripts/check_availability.py` 检查公网 `dyfire.cn` 的就绪、版本和执行服务健康。GitHub Actions 每 15 分钟执行，失败由 GitHub 自带通知报告。`/health/execution` 只公开 ready/degraded，内部核对所有已配置 Worker 分片、Auth 心跳和监控采样；不公开客户或主机详情。它检查经过香港桥接的整条链路，不能独自区分香港网络和成都网络故障。

## 浏览器回收测量

`python scripts/browser_capacity.py --slots 2 --rounds 2` 使用真实 Chromium、假 Cookie、本地 DOM 和截图，并拦截全部网络。部署镜像不默认包含运维脚本，可从检出的同版本源码在隔离容器中挂载运行。禁止挂载生产数据或凭据，容器使用 `--network none`。

2026-11-07 成都测量：1 CPU / 768 MiB 限额隔离容器，两个浏览器、两轮操作；各轮约 0.266–0.296 秒；开启时 12 个浏览器进程，关闭后 0；重开仍可读取假 Cookie。RSS 加总为 790668 KiB，会重复计算共享页，不能当作容器实际物理内存。此实验验证回收/恢复，**不证明真实抖音账号容量或发送吞吐**。

## 密钥轮换

`python -m spark_console.key_rotation --database SOURCE --old-key OLD --new-key NEW --output NEW_DIRECTORY` 仅生成新目录的数据库副本与校验报告，覆盖账号、邮件、邀请码和兑换码密文。不会覆盖运行库或自动启用新密钥。新旧密钥文件应由管理员单独妥善保存，不打印内容；不能把旧库配上新密钥直接启动。

更换时需要先停止写入、确认没有发送中的任务，核对输出数据库完整性、外键、报告的 key id 和已有资料解密。尚未使用的重置码/邮件验证码因 HMAC 换钥而失效，需要重新申请。切换操作必须同时更换数据库和密钥，并保留配套恢复点；本批部署不轮换生产密钥。

## 更新恢复点

`python deploy/snapshot_inventory.py --verify` 默认只读，列出已有恢复点、大小及清单验证结果。旧副本没有 manifest 时保留为 legacy；新副本检查 DB/WAL 的哈希和数据库完整性。只有显式 `--apply` 才按预算删除候选项；没有后台自动清理。

## 仍需实际条件的验收

苹果/安卓实体键盘、读屏和系统返回；真实抖音挑战与同设备扫码；真实抖音混合负载；SMTP 实际送达。上述验证不能由桌面模拟宽度、假 SMTP、隔离 DOM 或截图替代。自检不会发送消息；不确定的已提交消息只有精确原回执证据才能转为成功，否则保留待核实，不重发。
