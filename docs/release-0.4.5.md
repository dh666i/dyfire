# Dyfire 0.4.5

延续已认可的暖橙、圆角和玻璃导航，将首页、任务、账号、执行记录、订阅及管理员页面统一为同一套界面。

- 暂停、恢复、编辑和新建任务在原位置显示反馈；服务端确认后再显示成功。刷新失败保留已有内容。
- 账号检查区分排队、处理中、明确需要本人验证和确认恢复，等待超时后仍可读取最终结果。
- 手机端优化弹窗可视高度、长姓名、触控热区与 Dock 避让；模拟键盘通过，真实设备仍需持续验收。
- 用户管理支持独立移除筛选条件；连续切换用户和审计详情时忽略旧请求。
- 资源和发送图表支持鼠标、触屏、键盘查看，准确区分真实零值、缺测和读取失败。
- 管理模块按需加载；重复与停用样式已清理，字体和组件许可证随构建保留。
- 通知使用独立计时：悬停、聚焦、按住和页面后台时暂停，恢复后继续剩余显示时长。

通知入场采用固定命中区域的淡入效果，避免卡片从屏幕外滑入时离开静止鼠标。Linux 轨迹已确认原问题为卡片上移后鼠标实际落在其外。

本版不修改后端业务逻辑、数据库结构或发送任务规则，适合使用现有 Web 独立更新通道。

0.4.3 的发布被云端通知悬停回归阻止，没有生成正式 Release、没有部署到生产。保留原标签记录；0.4.4 随后被入场命中区域移动的悬停回归阻止，也未发布或上线。本修复版采用 0.4.5。

构建与测试运行环境固定为 Ubuntu 24.04，与当前 Playwright 支持范围及生产基础系统一致。GitHub Actions 的完整质量门禁、容器验收及安全扫描成功后才创建正式 Release。
