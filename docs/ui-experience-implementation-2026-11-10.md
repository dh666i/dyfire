## 验收范围

浏览器自动化覆盖 360、390、430、768、1280、1440、1920px，普通用户与管理员、深浅主题；包含首页、任务、账号、执行记录、订阅、账户中心、通知、帮助和管理页面。额外验证 0/1/3/20/100 条任务的布局、紧凑编辑、焦点恢复、下拉 Esc、提示计时、单一热力图提示、云端旧画面保护、兑换确认、主题与返回位置。

可访问性检查覆盖 390/1440px、两种主题和两种角色；它不能替代人工视觉与真机测试。动画正常模式和系统减少动画模式分别验证。

监控接口的时间桶值为区间峰值，因此图表明确使用“最近区间”“区间均值”，不把它们当成逐秒当前值或连续采样的算术均值。

本轮没有增加 UI 库依赖。共用交互已从大页面抽成组件；没有为视觉调整更换框架，也没有批量引入另一套弹层库。可选的主题扩散特效未采用，保留更稳定的颜色过渡。
