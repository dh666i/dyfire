# Dyfire 0.4.14

## 新增

- 好友卡片、续火任务和选人列表使用本站火花图标。昵称旁显示平台观测到的天数，点亮的好友优先排列。
- 选人时可以在全部已同步会话中搜索昵称、备注或抖音号。更换搜索词会保留勾选；同步后尽量保留阅读位置，并提示发生变化的火花。
- 从首页进入今日执行记录时自动按北京时间和所选状态筛选，可以清除日期查看历史。

## 修复

- 修复历史火花天数较高的熄灭好友挤到点亮好友之前、手机窄屏长昵称被挤没的问题。
- 更换兑换码后会作废旧预览，避免旧请求返回后显示另一张兑换码的权益。
- 接收邮箱和提醒偏好分别显示保存、失败及重试状态，反馈跟随用户正在操作的设置。
- 今日汇总按全天计算，执行量超过近期记录显示上限时仍能和详情对应。

## 兼容性与升级

- 沿用现有数据库和账号绑定，按正常镜像更新流程升级即可。
