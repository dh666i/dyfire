# 备份与恢复

备份每六小时运行，位于 `/opt/dyfire-backups/snapshot-*`，仅 root 可读。
每次使用 SQLite 在线备份，并执行 quick_check；包含对应密钥、环境和镜像标识。
当前为同机备份，不能防止整台机器或磁盘丢失。未配置异地目标，不宣称异地保护。
低于 2GB 空间时停止新备份，不自动删除已有备份。管理员在运维页检查最近状态。

恢复前应先停止 Web、认证、发送、监控服务，另存当前数据；在独立目录验证快照。
从 manifest 选择兼容镜像，恢复数据库与同份密钥，确认卷挂载和文件属主。
恢复后先保持发送器停止，检查旧任务执行记录、会员和账号，调整已过期排期以免补发。
先启动 Web 确认健康，再恢复认证、监控和发送。不要把历史 Cookie 当作仍有效的登录。
此文档是恢复流程；自动备份不会执行恢复、覆盖生产数据库或发送任何消息。
